# 📸 snapgram

A modern, fast, and interactive social media web application. Developed under the `liaddj/snapgram` architecture.

🔗 **[Click Here to Login & Explore the App](https://now-me-ssw6.vercel.app/)**

## ✨ Key Features

* **🔐 Secure Authentication:** User signup, login, and session management powered by Appwrite.
* **📝 Dynamic Posting:** Create and edit posts with an advanced drag-and-drop image uploader.
* **❤️ Social Interactions:** Like posts and save your favorite content to a dedicated personal tab.
* **📜 Infinite Scroll:** Seamless, infinite content browsing utilizing performance-optimized dynamic loading.
* **🔍 Explore Page:** Real-time search and filter system to discover trending posts and creators.

---

## 🛠️ Tech Stack

* **Frontend Framework:** React 19 + TypeScript + Vite
* **Backend as a Service (BaaS):** Appwrite
* **State Management:** TanStack React Query (v5)
* **Styling & UI:** Tailwind CSS + Radix UI + Lucide Icons
* **Forms & Validation:** React Hook Form + Zod
